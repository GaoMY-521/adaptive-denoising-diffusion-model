# Adaptive Conditional Denoising Diffusion Model with Hybrid Affinity Regularizer for Generalized Zero-shot Learning

This repository contains the official implementation of the paper:  
**"Adaptive Conditional Denoising Diffusion Model with Hybrid Affinity Regularizer for Generalized Zero-shot Learning"**  

Paper link: [https://ieeexplore.ieee.org/abstract/document/10415463](https://ieeexplore.ieee.org/abstract/document/10415463)

## Dataset

The dataset used in this project can be downloaded from the following link:  
[http://datasets.d2.mpi-inf.mpg.de/xian/xlsa17.zip](http://datasets.d2.mpi-inf.mpg.de/xian/xlsa17.zip)

## DDPM Related Code

The DDPM-related code is adapted from: [https://github.com/lucidrains/denoising-diffusion-pytorch](https://github.com/lucidrains/denoising-diffusion-pytorch)
